## Overview

A client object, `JellyfinClient`, holds identity, server and token, and typed sub-APIs are accessed through
it. [dart_plex](/projects/dart-plex) has the same structure, so an app can support both servers the same way.

## Features

- **Built on the official OpenAPI spec**: endpoint names, field names and casing match api.jellyfin.org.
- **Typed DTOs**: every response is a typed object that also keeps its `.raw` map, so fields added by newer
  servers are kept.
- **Both auth flows**: `authenticateByName()` and the Quick Connect link flow.
- **Synced lyrics**: parsed lines with tick-to-ms helpers and `.toLrc()` output.

It's pure Dart (no native plugin, no Flutter dependency) and runs anywhere Dart does.
