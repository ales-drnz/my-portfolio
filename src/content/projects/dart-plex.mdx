## Overview

A client object, `PlexClient`, holds identity, server and token, and typed sub-APIs are accessed through it.
[dart_jellyfin](/projects/dart-jellyfin) has the same structure, so an app can support both servers the same way.

## Features

- **plex.tv sign-in**: legacy credentials or the official 4-character PIN flow at plex.tv/link.
- **Server discovery**: owned and shared servers with connection candidates; `bestConnection()` picks local
  first, then HTTPS, then relay.
- **Streaming URLs**: `universalAudioUrl()` builds HLS or DASH manifests, `directFileUrl()` the
  zero-transcode original.
- **Semantic errors**: every failure is a `PlexException` you can branch on, instead of raw network errors.

It's pure Dart (no native plugin, no Flutter dependency) and runs anywhere Dart does.
