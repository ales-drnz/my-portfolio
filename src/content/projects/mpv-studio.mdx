## Overview

MPV Studio is where [mpv_audio_kit](/projects/mpv-audio-kit) gets used the way a real app would use it, and
where new engine features are tried first. The media server clients plug into it as well:
[dart_smb2](/projects/dart-smb2), [dart_jellyfin](/projects/dart-jellyfin) and [dart_plex](/projects/dart-plex).

## Features

- **Playback**: cover art, metadata, a scrubbable waveform, chapters, an A-B loop with a repeat count, speed
  and volume, all driven by the engine's reactive streams.
- **Visualizers**: a log-spaced spectrum, a VU meter and a waveform seekbar that fills in as network tracks
  decode.
- **Queue**: reorderable, gapless, and each row says where the track comes from and whether it played, was
  skipped or failed.
- **Stream**: reference streams in every common codec, any URL with its own HTTP options, a source resolver
  for links that expire, and Jellyfin, Plex and Samba libraries.
- **Effects**: the signal chain rack, with interactive editors for each stage.
- **Engine and console**: an inspector for the engine's state and a raw mpv command console.

The layout adapts from a phone in portrait to an ultrawide desktop, in a dark and a light theme, with a
right-click menu and keyboard control on desktop and long press and swipe on phones.
