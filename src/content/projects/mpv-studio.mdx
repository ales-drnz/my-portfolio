## Overview

MPV Studio is where [mpv_audio_kit](/projects/mpv-audio-kit) gets used the way a real app would use it, and
where new engine features are tried first. The media server clients plug into it as well:
[dart_smb2](/projects/dart-smb2), [dart_jellyfin](/projects/dart-jellyfin) and [dart_plex](/projects/dart-plex).

It runs on Android, iOS, macOS, Windows and Linux, and **[in the browser](https://ales-drnz.github.io/mpv_studio/)**:
the full app, with libmpv running as WebAssembly, best in Chrome or Edge. There a web page can't open an SMB
connection or reach `http://` servers from an HTTPS page, so Samba and plain-HTTP sources are left out.

## Features

- **Playback**: cover art, metadata, a scrubbable waveform with chapters, an A-B loop with a repeat count, speed
  and volume, all driven by the engine's reactive streams.
- **Visualizers**: a smooth real-time spectrum, a VU meter and a waveform seekbar that fills in as network tracks
  decode.
- **Queue**: reorderable and gapless; each row shows the track's tags and source, and whether it played, was
  skipped or failed, and why.
- **Stream**: a lab of reference streams, chapters, a source resolver for links that expire, and Jellyfin, Plex
  and Samba libraries to browse and search.
- **Effects**: a signal chain rack edited while the music plays, with quick editors for EQ, compressor and the
  rest, the whole lavfi catalog, and a live view for each stage with before and after meters.
- **Engine, settings and console**: what the engine is doing right now (cache, scans, formats, the chain), every
  setting a search away, and an mpv command console with the live engine log.

## Desktop and mobile

The layout adapts from a phone in portrait to an ultrawide desktop, in a dark and a light theme, with a
right-click menu and keyboard control on desktop and long press and swipe on phones.
