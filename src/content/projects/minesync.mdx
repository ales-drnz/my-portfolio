## Background

A shared Minecraft world needs a host. A dedicated server adds cost and maintenance, and when the host is one
friend's PC, the world is only there while that PC is on. With MineSync anyone in the group can host: the world
lives on a small hub, on a NAS for example, and each evening starts from its latest version on whoever's PC presses
Play.

Version 0.1.0 is a rewrite in Dart and Flutter: the hub, its web pages, a desktop app for Windows, macOS and Linux
and a command line, sharing one protocol and one sync engine.

## Playing

The home lists every server, who is hosting it and the address to join. Pressing **Play** takes the server's lock
on the hub, so two people never run the same world, downloads what changed since the last session, finds a
suitable Java on the PC and starts the server.

- **Saved while you play**: every five minutes the app asks the server to flush the world, takes a snapshot and
  uploads what changed in the background, within a bandwidth limit. The game never stops; closing uploads the
  final state and frees the lock.
- **A host that stops answering** is shown as such: it can resume from the same PC, and an admin can free the
  server after two confirmations.
- **Nothing lost by surprise**: changes on a PC that never reached the hub are kept and shown, never overwritten,
  and mass deletions or saves on an old base are refused.
- **A real server session**: the steps from update to stop, a console with filters and commands, the players
  online, restarts after a crash and an automatic stop when nobody has been online for a while. The hub checks
  that the host's port answers.

## Mods and the player pack

The Mods tab lists a server's mods with their icons, finds new ones on Modrinth with their dependencies, and offers
updates that fit the server's Minecraft version and loader. Changes are collected first and applied together at
the next Play. Each mod says where it is needed, on the server, for the players or both, and the hub builds the
**player pack** from that list, ready for Prism Launcher or the official launcher. New servers start from scratch,
from a Modrinth modpack or `.mrpack`, or from a server folder you already have.

## History

Every save is a version with an author, a time and the files that changed. Going back to one never deletes the
newer ones: it adds a new version with the old content, and any version can be downloaded as a ZIP. Files are split
into pieces stored once by their hash, so a hundred versions of a world cost little more than one. By default the
hub keeps the last 30 versions, every version of the last 24 hours and one per day for a week, and shows what a
cleanup would remove before doing it.

## The hub

The hub is a Dart program in a small multi-arch Docker image, running next to ZeroTier on an always-on machine and
reachable only from inside the ZeroTier network. Its web pages, Flutter for the web, show the servers, the
activity and the downloads, and an Admin area holds history rules, protection, sessions, members, DNS and Telegram,
each applied at once without a restart. An optional built-in DNS points `zerotier.<server>.<zone>` at whoever hosts
tonight, so the address in Minecraft never changes, and a Telegram bot says when a server opens and closes.

## Access and updates

MineSync has no accounts or passwords. The hub recognises each request by its ZeroTier membership through ZTNET,
so adding a friend means authorising them in ZTNET, and the ZTNET token never leaves the hub. Worlds stay on the hub
and on the PC of whoever hosts, and game traffic goes straight from the players to the host.

The app updates itself from the hub, checks the signature of every package and goes back to the previous version
if the new one doesn't start. It speaks English and Italian, with light and dark themes, two palettes, larger
interface sizes, keyboard and screen reader support, and never colour alone for a state; the screenshots on this
page are drawn by its own tests.
